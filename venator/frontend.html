Operations / Submit payment

Submit a payment

Hand the system a real incoming payment. It is triaged automatically the moment it arrives — no button, no queue worker, one model call. The verdict below is what the agent decided on its own.

New payment

What happens

1Facts are read — transaction, link, recipient.
2The model reads the message. Opinion only.
3The guard decides. Rules fire, first match wins.
4State is written. One writer, and it validates.

This runs once, on arrival. Submitting the same thing again is a new payment, not a re-run.
